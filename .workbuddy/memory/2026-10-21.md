# 2026-10-21 第七轮：商城换真实美术 + 修滚动区全空白

## 本轮改了什么

**1. `FoodDetailPopup` 效果列表从富文本改成左右两列 Text（`Assets/Scripts/UI/PetPopups.cs`）**
- 起因：`<align='right'>` 标签在 uGUI 富文本里**不被支持**，会被当普通字符原样打到屏幕上。
  实测排除法：`<color='#ff0000'>` 单引号、`<color="#00aa00">` 双引号都正常染色；
  `<size=60>` 正常变大；只有 `<align>` 原样显示（截图 `IconPreview/shot_aligntest.png`）。
- 现在是「EffRow 行池」：Build 时建 3 行（Label 左对齐 + Value 右对齐，各 Fill 整行靠 alignment 分工），
  Show 时按食物填内容、设 offset、`SetActive`，多余的置 inactive。
- **行池而不是每次新建/销毁**：`Object.Destroy` 要到帧末才生效，
  同一帧连开两次弹窗会看到旧行叠在新行上（实测连开 beef→normal 时 Effects 下挂了 8 个子节点）。
- 行数不足三条时整体垂直居中（`topPad = (180 - contentH)/2`），不贴顶留空白。
- 常量：`EffectBoxHeight=180`、`EffectRowHeight=54`、`EffectRowGap=9`、`MaxEffectRows=3`。

**2. 修掉滚动区整个空白的静默失效（本轮最大的坑）**
- 症状：商店/食品/场景三个页面的滚动列表**一张卡片都不显示**，而 rect、文本、sprite、fillAmount
  全部量得到，Console 零报错。之前两轮截图都漏了它（弹窗挡住 + 没细看）。
- 根因：Viewport 上当 Mask 用的那张 Image，color 写成 `new Color(1,1,1,0.001f)`「几乎透明但可射线命中」。
  **alpha 0.001 转成字节是 0 → CanvasRenderer 整条绘制被跳过 → 模板缓冲一个字都没写 →
  所有子项都过不了 NotEqual 测试 → 全被裁掉。**
- 修法：`mask.color = Color.white` + `showMaskGraphic = false`（只写模板不上屏，不靠 alpha 藏）。
  改动两处：`PetPageBase.MakeScrollable` 与 `ShopPage.BuildGrid`。
- 判据（下次直接量这个）：截图文件字节数 26933 → 74766。
- `PetUIFactory.NewHitArea` 里那个 `new Color(0,0,0,0.001f)` 不用动 —— 它只做射线命中，不当 Mask 图形。

**3. 修 `ScenePage.Refresh()` 的粘滞提示**
- 原来只在「库为空」分支里 `SetActive(true)`，从不关回去。
  启动时 `library` 还没赋值，Refresh 先跑一轮空判把「场景库为空」打开，之后库到了也没有第二次空分支来关。
- 修法：非空分支显式 `SetActive(false)`。

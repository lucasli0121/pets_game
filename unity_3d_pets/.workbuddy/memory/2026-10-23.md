## 离线渲染 UI 截图（以前用 ScreenCapture 会静默不落盘）

`ScreenCapture.CaptureScreenshot()` 在编辑器里**不保证出文件**（这次绝对路径调用后磁盘上什么都没有，
之前那批 `shot_*.png` 是别的状态下碰巧成的）。可靠做法：

1. 进 Play，让 `Start()` 把 UI 建起来（`frame` 会走，本次 frame=265，Game 窗口没聚焦也能动）
2. 造状态 → `ui.NotifyStateChanged()`（会走到 `RefreshAll()` → 当前打开的浮层 Refresh）
   —— 别用 `Show()`，它会触发 `RefreshFromServer()` 把假状态冲掉
3. 把 `CheckInMask` 临时 `SetParent` 到自建的 ScreenSpaceCamera 画布，
   正交相机 orthoSize=200 / aspect=1400/800 / RT 1400×800 → 面板 700×400 正好 2x 铺满
4. `cam.Render()` → `ReadPixels` → `EncodeToPNG` → `File.WriteAllBytes`
5. 还原 parent 与 sibling index，DestroyImmediate 临时相机/画布

`GameObject.Find("CheckInMask")` 找不到 inactive 物体（返回 NULL 不是代码错），
要 `ui.transform` 下 FindDeep("PopupLayer") 再 `.Find("CheckInMask")`。

产物：`IconPreview/shot_checkin_cells.png`（7 天全未签）、`shot_checkin_mixed.png`（19/20/23 已签）。

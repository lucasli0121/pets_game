### 1. 场景形态从 3D 改为「2D 背景图 + 3D 宠物」——**推翻 PetHome 现有做法**
PRD 4.5「场景表现形态（技术约束，2026-10-18 定）」：

## 修掉的三个 bug

### 1. SetPrivateField 对装箱枚举失效（静默）
`PetRegion.Body` 是装箱枚举，`value is int` 恒为 false，
于是 `prop.intValue` 被赋 0 —— **所有触摸分区全是 Unknown**。
不报错，触摸也照样能命中（判定的是有没有 PetRegionCollider，
不是它的 region 值），只是「点头」和「点背」行为完全一样。

修法：
```csharp
prop.intValue = value is Enum en ? Convert.ToInt32(en)
                                 : (value is int idx ? idx : 0);
```
**不用 `enumValueIndex`** —— 那是声明顺序索引，枚举有跳号或负值时会整体错位。
其余分支（bool/float/int/LayerMask）传的都是真值类型，只有 Enum 这一路是装箱的。

### 2. 比例分区混用了世界坐标与本地坐标
主场景狗转了 180°，世界 bounds 的 +Z 已经是模型本地 -Z（尾侧）。
用世界 bounds 算归一化比例 → 尾巴摆到了狗前面（朝相机那侧）。

修法：用 `Renderer.localBounds` 算，然后 `localPosition` 赋值。
判断依据：Head 走骨骼所以没暴露问题，Tail 走比例所以暴露了。

### 3. 归一化坐标写了负数
`tail.center.z = -0.55` —— 归一化范围是 0~1。
`RatioToWorld` 算成 `min.z + size.z * (-0.55)`，直接跑到包围盒外面。

正确取值：**z=0.5 是身体中点，>0.5 才是头侧**。
改成 head.z=0.82 / back.z=0.52 / tail.z=0.16。

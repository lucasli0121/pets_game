# 宠屋养成记 V1 — 三端分发与版号资质清单

> 适用：Windows 桌面 / Android / 微信小游戏 三端
> 主体：企业（非个人）
> 变现：V1 纯 IAA（激励视频）；虚拟支付推迟到版号下来之后
> 整理日期：2026-10-17（2026-10-18 更新产品名与软著口径）

---

## 0. 一页结论

**已定路线（2026-10-17）：V1 走「微信小游戏 + 纯 IAA」，暂不申请版号、暂不接虚拟支付。**

目标是「上线快、少花钱」。据此 V1 的对外版本只有微信小游戏一端；Android / iOS / Windows 对外发售全部推迟到版号下来之后。

| | 本路线（IAA 免版号） | 放弃的路线（IAP + 版号） |
| --- | --- | --- |
| 上线周期 | **约 2–3 个月**（瓶颈在开发，不在资质） | 8–12 个月 |
| 资质花费 | **约 2,000–4,000 元**（软著 + 企业认证） | 7 万–9 万 |
| 对外可上 | 微信小游戏 | 三端 |
| 变现 | 激励视频广告 | 虚拟支付 |

以下为完整依据与边界。

1. **版号不是你自己去申请**，而是由持《网络出版服务许可证》的**出版单位代为申报**。你能做的是把前置资质和材料准备好，然后付出版服务费。
2. **三端可以共用一个版号**，但 PC 属「客户端」载体，必须在申报时一起**增报**，不能事后补。（本路线暂不涉及）
3. **虚拟支付必须写进申报材料**（付费规则是说明书必备项）。先按无内购申报、后加内购，要走变更审批。
4. **若将来改走 IAP，资质线是最长关键路径**：软著 + ICP 许可证 + 版号，串起来现实周期 **8–12 个月**。
5. 申报时**游戏开发进度需不低于 75%**——所以资质线和开发线必须并行，不能串行。

微信小游戏账号已注册，名称已锁定。以下四处必须完全一致，任何一处对不上都会在后续审批中被驳回。

| 用途 | 填什么 |
| --- | --- |
| 微信小游戏名称 | 宠屋养成记 |
| 微信小游戏简称 | 宠屋 |
| 软著全称 | 宠屋养成记游戏软件 V1.0 |
| 版号游戏名 | 宠屋养成记 |

六条硬约束：

1. 微信账号名称 4–30 字符，1 个汉字 = 2 字符。「宠屋养成记」= 10 字符。
2. 简称只能从名称中按顺序连续选取，长度 4–10 字符。所以只有「宠屋」「宠屋养成」「养成记」三种可选，不能自造。
3. 微信小游戏名称与账号主体在**备案后锁定**，不可改名、不可改主体。
4. 软著著作权人名称必须与微信账号主体（营业执照全称）**完全一致**，差一个字即驳回。
5. 软著名称不能只写「宠屋养成记」，必须体现软件功能，所以加「游戏软件」后缀。
6. 名称中不要出现「微信小程序版」「手游版」这类平台后缀。将来版号要覆盖小游戏 + APP + PC 三端，加了平台词后面全对不上。

## 2.5 IAA 与 IAP 的资质分界（关键）

| 场景 | 微信小游戏 | 抖音小游戏 | **原生 APP（安卓 / iOS）** |
| --- | --- | --- | --- |
| **纯 IAA**（无任何充值、道具付费） | 版号 **⚠️ 平台准入可豁免** | ⚠️ 可豁免 | **✅ 强制，无豁免** |
| **IAP**（开通虚拟支付 / 道具付费） | 版号 **✅ 强制不可豁免** | ✅ 强制 | ✅ 强制 |
| ICP 许可证（纯 IAA） | ❌ 平台托管豁免 | ❌ | **✅ 强制** |
| 文网文 | ❌ 非强制 | ❌ | ❌ 非强制 |

**三条边界必须记住**

1. **「平台准入豁免」不等于「法律豁免」。** 法规口径（《网络出版服务管理规定》第二十七条）是「网络游戏上网出版前必须审批」，有合规服务商明确表述「无论是否收费、无论内购还是广告，都属正式运营，必须版号」。微信在实操中对纯 IAA 休闲品类放行，属于平台层面的口径，政策会调整。对比表本身也标注：「仅代表上架平台准入要求，不代表完全规避监管长期风险」。
2. **「无版号品类」的范围由微信界定。** 玩法超出范围时，即使无内购也可能被要求补版号。
3. **免版号只对小游戏成立，对独立 APP 不成立。** Android APP 即使纯 IAA，也要版号 + ICP 许可证。

**本项目算不算「纯 IAA」**

关键是金币怎么来：

- 金币只能靠**看激励视频**获得、商品只能用金币买 → 属纯 IAA，可走免版号
- 只要有任一指向内购：金币可充值 / 付费解锁 / **抽奖开箱** → 立即变 IAP，版号强制
- **红线：不要做抽奖 / 开箱付费机制**，那是监管重点核查项

**建议策略：两条线并行**

- IAA 版本先上线（13–37 工作日，走免版号）拿真实用户验证
- 版号同期申请（4–6 个月），下来后企业主体可在后台开通虚拟支付，升级为 IAP
  （企业主体可直接升级；个人主体不行，必须重新注册账号）
- IAA 的代价：ARPU 远低于内购；微信 IAA 分成 30 天最高 90%、90 天最高 85%；开流量主需 UV ≥ 1000；「金币经济」需重设（只能靠看广告产出）

### 需要办的资质（只有这些）

| 项 | 费用 | 周期 | 说明 |
| --- | --- | --- | --- |
| 企业微信认证 | 300 元/年 | 1–3 工作日 | 小游戏账号必须企业认证 |
| **软著** | 自办 ≈300 元 / 代办 1,000–2,000 元 | 30–60 天（可加急） | 企业主体强制 |
| 小程序备案 | 免费 | 数个工作日至数周 | 微信代报工信部 |
| 自审自查报告 | — | — | 按微信模板填 |
| 适龄提示 | — | — | 必填 |
| 隐私协议 | — | — | 首屏合规弹窗 |
| **合计** | **约 2,000–4,000 元** | — | 版号 / ICP 证 / 文网文 全部不办 |

### 必须做的产品改动（否则会被判成内购）

1. **金币降级为「游戏内积分」**，不是货币。全站文案不得出现「充值」「购买」「元」「¥」。
2. **金币唯一产出口径 = 看激励视频**。PRD 里「金币来源待确认」必须补成这一条，否则纯 IAA 的经济闭环不成立（现有设计只有花币、没有赚币）。
3. **移除任何充值入口**，包括灰掉的按钮——审核会看。
4. **不做抽奖 / 开箱 / 概率奖励付费**。监管重点核查项。
5. **商店只卖金币能买的东西**，不得出现付费礼包、限时折扣包。
6. 场景解锁（home 免费 / garden 100 / park 200 / night 300 金币）可以保留，因为金币非付费获得。

### 时间线（与开发并行）

```
Week 1      企业认证 + 提交软著 + 提交小程序备案
Week 1–8    软著出证（30–60 天，可与开发并行）
开发期      补齐喂养 / 商店 / 成长 / 存档 / 12 个 UI 页面 / 语音
开发后期    小游戏转换 + 首包裁剪（4MB）+ CDN 资源外置
提审        13–37 个工作日
```

**关键路径是开发，不是资质。** 资质不构成瓶颈，这是本路线最大的收益。

### 本路线明确放弃的东西

| 放弃项 | 原因 | 何时能拿回 |
| --- | --- | --- |
| 虚拟支付 / 内购 | 需要版号 | 版号下来后 |
| Android APP 上架 | 原生 APP 纯 IAA 也强制版号 + ICP 证 | 版号下来后 |
| iOS APP 上架 | 同上（且需要 Mac） | 版号 + Mac |
| Windows 对外发售 | 国内 PC 渠道都要版号 | 版号（需增报客户端） |
| 文网文 / ICP 许可证 | 小游戏平台托管豁免 | 只在做 APP 时需要 |

> Windows 版仍可出 exe 作**内部测试与真机验收**，不对外分发、不收款，这不涉及资质。

## 2.7 软著申请（V1 第一优先，现在就该启动）

### 为什么现在办

- 微信小游戏上线审核要求提供「软著 或 电子版权认证」
- 软著是将来申报版号的**唯一**认可材料，电子版权认证不能报版号
- 普通登记免官费，周期 30–60 个工作日；加急 3–15 个工作日，费用 1,000–5,000 元

### 材料清单

| 材料 | 要求 | 现状 |
| --- | --- | --- |
| 申请表 | 中国版权保护中心在线填报，功能说明 500–1300 字 | 待填 |
| 源程序 | 前 30 页 + 后 30 页，每页 ≥50 行，页眉标软件全称与版本号 | 已有：26 文件 5,824 行 = 116 页 |
| 说明书 | 10–30 页，每页 ≥30 行，含功能、运行环境、操作说明 | **缺**，需单独编写 |
| 身份证明 | 营业执照副本扫描件 | 待准备 |
| 签章页 | 经办人黑色中性笔手抄承诺 + 签名 + 身份证号 | 2026 新规必做 |

### 当前三个缺口

1. **说明书页数不够**。现有 PRD 5,842 汉字约 5–6 页，软著要求 10–30 页。
2. **代码范围与产品描述不一致**。PRD 里的喂养、商店、积分、成长、12 个 UI 页面、账号，代码中均未实现。
3. **AI 声明问题**。2026-03-15 起签章页须手抄「未使用 AI 开发编写代码、撰写文档或生成登记申请材料」。当前代码为一次性生成（git 首次提交即带入 5,824 行），签字前须完成实质人工改造。

### 建议顺序

1. 先用**电子版权认证**（3–5 个工作日，最快 1 天）通过微信小游戏的版权审核，不阻塞上线
2. 同步做代码实质改造 + 说明书编写
3. 功能补齐后提交传统软著，用于将来版号申报

> 电子版权认证的边界：可上架，**不能报版号**，不能用于维权、高企认定、政府补贴。

## 3. 版号申请：怎么做

### 3.1 前置条件（缺一不可）

官方受理条件原文（上海一网通办·出版国产网络游戏作品审批）：

1. 出版单位须为具有网络游戏出版范围的**网络出版服务单位**
2. 所申报作品已办理**著作权登记**，或相关公证，或著作权人明确的自我声明（承诺）
3. 游戏著作权人须为**中国公民或内资企业**
4. 游戏运营机构须具有 **《电信与信息服务业务经营许可证》（ICP 证）**
5. 作品符合《出版管理条例》《互联网信息服务管理办法》《网络出版服务管理规定》
6. 运营中必须符合国家有关保护未成年人的相关规定
7. **游戏开发进度不低于 75%**，不能以 DEMO / 半成品申报
8. 必须已接入**国家统一实名认证 + 防沉迷系统**

> **审批本身不收费**（上海政务网原文：审批收费「否」）。费用全部来自出版单位 / 代办的服务费，属于市场行为，不是法定收费。

**出版服务费真实行情（2026）**

| 来源 | 口径 | 金额 |
| --- | --- | --- |
| 炫彩互动（爱游戏开放平台）2026-07 公开价目表 | 原广电总局《移动游戏出版服务管理通知》**第三条范围**（休闲益智类） | **35,000 元/款** |
| 同上 | 第四条范围（其他移动游戏） | **45,000 元/款** |
| 同上 | 进口游戏 | 60,000 元/款 |
| 行业统计（300+ 休闲游戏项目） | 休闲类代办服务费 | **2 万–5 万** |
| 其他代办 | 休闲类版号代办 | 3 万–4.5 万 |

**注意两项条款**
- 炫彩的价目表写明：**「非因出版需求方原因造成申请未批准，全额退还」**；因需求方原因（不按时补材料、不按要求修改）不予退还。谈合同时一定要争取这一条。
- 增报客户端是否额外收费、审核意见反复修改是否加价，**须单独确认**。

**容易混淆：5 万–20 万 是什么**
这是「中重度游戏 + 全案代办打包价」的口径，通常一并包含 ICP 许可证、文网文、防沉迷、等保等，不是单版号的价格。本项目属休闲类，按上表 3.5 万档估算即可。

**本项目资质预算（一次性）粗算**

| 项 | 自办 | 代办 |
| --- | --- | --- |
| 软著 | ≈300 元 | 1,000–2,000 元 |
| ICP 许可证 | ≈0 | 8,000–15,000 元 |
| 版号出版服务费 | — | **35,000 元**（休闲档） |
| 文网文（若不发安卓商店可暂缓） | — | 15,000–25,000 元 |
| 防沉迷 SDK | — | 1–2 万/年（自研约 3–5 万） |

### 3.2 五步流程与时限

| 步骤 | 内容 | 时限 |
| --- | --- | --- |
| 1. 前期准备 | 办软著、ICP 许可证、防沉迷接入、内容自检 | 1–3 个月（可与开发并行） |
| 2. 材料准备 | 三大类材料，出版单位打磨，提交前模拟审核 | 2–4 周 |
| 3. 出版单位初审 | 价值观导向、防沉迷落实 | 15–20 工作日 |
| 4. 省级初审 | 形式审核 5 工作日 + 实质审核（内容导向）20–30 工作日 | 25–35 工作日 |
| 5. 国家终审 | 意识形态、文化内涵；含专家评审 + 社会公示 | 40–60 工作日 |

- 合计（不含前期准备）：**3–6 个月**
- 审核意见反馈时限统一 **10 个工作日**，来回修改会拉长周期
- **选北京、上海等试点区域申报，周期可缩短约 30%**
- **休闲益智、教育科普类可享差异化审核支持，周期相对缩短约 20%**
- 结果：**国家新闻出版署 ISBN 号 + 《网络游戏出版物号核发单》**，有效期无限期

### 3.3 材料清单（三大类）

**A. 基础资质**
- 营业执照（加盖公章）
- **ICP 许可证**
- 软件著作权证书复印件（加盖公章）

**B. 游戏内容**

### 3.4 高频驳回点（本项目要重点防）

| 风险 | 说明 |
| --- | --- |
| 软著名称 ≠ 版号申报名称 | 两者必须完全一致，否则驳回 |
| 以 DEMO / 未完成版本申报 | 需开发进度 ≥ 75%、完整包体 |
| 防沉迷未接入或不合格 | 2021 年后是「一票否决」项 |
| 抽奖 / 随机奖励未公示概率 | 本项目若做盲盒类道具必须公示概率 + 保底 |
| 诱导未成年人消费 | 充值界面文案、弹窗都要审 |
| 付费规则缺失 | 金币 → 道具的定价、兑换比例必须写清 |
| 无版号先上线 | 属非法出版，下架 + 罚款 |

### 3.5 品类选择（影响周期）

- 2025 年过审版号中，**休闲益智占比 44.7%**，模拟经营 + 儿童教育合计 31.2%
- 2025 年过审版号中**大厂仅占 15.3%**，中小团队有明显空间
- 本项目建议方向：按 **「移动-休闲益智」** 申报（不是「模拟经营」），可吃差异化审核支持、周期缩短 20%
- ⚠️ 但"电子宠物养成"是否被归到模拟经营，由出版单位与审核方判断——**这是可以争取的点，须与出版单位确认**

### 3.6 三端增报（关键）

- 2022-09-13 起允许在**原版号不变**的前提下**增报客户端 / 主机 / 页游版本**
- 反面案例：《哈利波特：魔法觉醒》只有移动版号，PC 版被判无证运营，2021 年底被迫下架
- 本项目申报策略：**主报「移动」，同时增报「客户端」**
  - 移动 = 微信小游戏 + Android（同一移动版号）
  - 客户端 = Windows
- ⚠️ 移动版号增报客户端后，能否同时覆盖微信小游戏版 —— **见 §5 待确认**

## 4. 现在就能做的（勾选清单）

- [ ] **1. 启动软著**：源代码 + 说明书，通过中国版权保护中心或代理提交（约 2 个月）。著作权人名称必须与主体一致。
- [ ] **2. 启动 ICP 许可证**：确认经营范围，向省通信管理局提交（40–80 工作日）。这条最容易被忽略，但官方受理条件是硬要求。
- [ ] **3. 找出版单位**：优先接触有网络游戏出版资质的出版社 / 出版公司，谈出版服务费和申报排期。
- [ ] **4. 定死游戏名称**：名称一旦申报就不能随意改，改名要走变更审批。软著、版号、各平台账号名称必须一致。
- [ ] **5. 防沉迷方案提前设计**：国家实名认证 + 830 新规（未成年人仅周五/六/日及法定节假日 20:00–21:00；8 周岁以下不得充值，8–16 岁单次 ≤50 元/月累计 ≤200 元，16–18 岁单次 ≤100 元/月累计 ≤400 元）。做进架构，不要后补。
- [ ] **6. 确定金币/内购的定价与兑换比例**：写进说明书，且微信侧代币比例发布后不可改。
- [ ] **7. 留住版权链**：AI 生成的 UI / 背景图保留生成记录，做足人工改造；软著与版号材料都要提交美术资源，权属说明要经得起问。
- [ ] **8. 三端目录与包体分离**：`Build Target` 分离资源，PC 包不进移动包；小游戏首包按 4MB 约束裁剪（见 §6）。

## 5. 待确认事项（编号，等你逐条回）

1. **移动版号增报客户端后，能否同时覆盖「微信小游戏版」？** 我不确定。须向出版单位确认，不能按「一个版号全包三端」规划。
2. **微信小游戏是否必须持有 ICP 许可证？** 官方受理条件写「游戏运营机构须具有 ICP 证」，但小游戏由微信提供网络服务，实操口径是否可用 ICP 备案替代——须向出版单位和微信侧确认。
3. **本项目能否按「移动-休闲益智」申报？** 电子宠物养成可能被判模拟经营，影响周期。
4. **Windows 版 V1 定位**：内部测试载体（不收款，零成本）还是对外销售（要版号 + 渠道）？
5. **出版服务费与合同条款**：按休闲档 3.5 万起谈；必须争取「非己方原因未获批全额退款」；确认增报客户端是否加价。
